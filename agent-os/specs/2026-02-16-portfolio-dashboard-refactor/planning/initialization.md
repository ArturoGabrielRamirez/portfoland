# Feature Initialization: Portfolio Dashboard Refactor

**Feature:** Portfolio Dashboard (Editor)
**Source:** Roadmap Item 19
**Initial Description:** Refactor and complete the Portfolio Dashboard editor at `/dashboard/portfolio`. The goal is to create a unified page to manage the public portfolio, specifically adding support for Contact Info management and Section Ordering (About/Bio, Experience, Skills, Projects). The current implementation only supports basic Bio, Profile Image, and Theme toggling.
