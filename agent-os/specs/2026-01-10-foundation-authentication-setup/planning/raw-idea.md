# Raw Idea: Foundation & Authentication Setup

**Feature:** Foundation & Authentication Setup

**Description:**
This is the foundational setup for Portfoland - a gamified career storytelling platform. This spec covers:

1. **Database Setup**
   - MongoDB Atlas connection
   - Prisma ORM configuration
   - Base data models (User, etc.)

2. **Authentication System**
   - NextAuth.js (Auth.js v5) implementation
   - Google OAuth as primary login method
   - Session management
   - Protected routes

3. **UI Foundation**
   - shadcn/ui component library setup
   - Base layout components
   - Theme configuration (supporting retro/pixel aesthetic later)

4. **Internationalization**
   - next-intl setup
   - English and Spanish language support
   - Language switcher

5. **Basic Dashboard**
   - Authenticated user landing page
   - User profile display

This is Phase 1 (v0.1.0) of the Portfoland roadmap.
