# Raw Idea: Subdomain Routing

**Subdomain Routing** - Enable username.portfoland.com subdomain routing with Next.js middleware. Users' public portfolios will be accessible via their own subdomain (e.g., `john.portfoland.com`) in addition to the existing path-based route (`/[locale]/[username]`).
