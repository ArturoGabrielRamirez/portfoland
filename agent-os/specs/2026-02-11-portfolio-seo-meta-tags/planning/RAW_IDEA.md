## Feature Description
Portfolio SEO & Meta Tags — Open Graph, structured data dinámico

## Roadmap Reference
- Roadmap Item: #18
- Size: S (Small)

## Raw Idea
Implement comprehensive SEO and meta tag support for portfolio pages with dynamic Open Graph tags and structured data. This includes:

- Dynamic Open Graph (OG) tags for social media sharing
- Structured data (JSON-LD) for search engine optimization
- Meta tags optimization for portfolio pages
- Support for internationalization (i18n) with next-intl
- Dynamic content generation based on portfolio data
